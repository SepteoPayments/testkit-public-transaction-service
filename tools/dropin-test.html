Drop-in test — API publique paiement

Colle le clientSession renvoyé par POST /sessions et monte le Drop-in Adyen (sandbox). Le Drop-in parle directement à Adyen, pas à notre API.

1 · Configuration

Client settings du credential Adyen. Origin autorisée requise : http://localhost:3000.

2 · Session

Renvoyé par notre API sur POST /sessions. Pour le cycle de vie complet, crée la session avec capture.mode = "MANUAL".

3 · Paiement


  


  

    Aide — comment obtenir le clientSession, servir la page, cartes de test

    
Servir la page sur localhost:3000 (obligatoire, pas de file://) — depuis ce dossier :

    
    
      
  • npx serve -l 3000 .  (Node)
    • 
      
  • ou python -m http.server 3000 puis ouvrir http://localhost:3000/dropin-test.html
    • 
    


    
Obtenir le clientSession (via la collection Postman) :

    
    
      
  1. Récupérer un token (script get-token.js / requête token de la collection).
    2. 
      
  2. POST /sessions avec Authorization: Bearer <token>, Idempotency-Key, et un body dont capture.mode = "MANUAL" (pour ensuite tester capture/cancel/adjust/extend).
    3. 
      
  3. Copier la valeur du champ clientSession de la réponse et la coller dans le champ ci-dessus.
    4.
